# Contributing to RHCSA EX200 Exam Labs

Thank you for considering contributing to this project! Whether you're fixing errors, adding new labs, or improving documentation, your help makes this resource better for everyone preparing for the RHCSA exam.

## 🚀 How to Contribute

### 1. Reporting Issues
Found a mistake or have a suggestion? Open an [Issue](https://github.com/your-repo/rhcsa-ex200-exam-labs/issues) with:
- Clear description of the problem/suggestion
- Relevant objective number (e.g., "Objective 3: LVM")
- For command errors: include the exact error message

### 2. Submitting Changes
1. **Fork** the repository
2. Create a **feature branch**:
   ```bash
   git checkout -b fix/objective2-systemd
