# Contributing

Thank you for considering contributing to this RHCSA EX200 practice repository!

## How to Contribute

- Report issues or suggest improvements by opening an Issue
- Submit corrections or new tasks via Pull Request
- Share additional practice scenarios or solutions

## Guidelines

- Keep tasks aligned with official Red Hat RHCSA EX200 objectives
- Clearly mark RHEL 9 vs RHEL 10 content
- Test all tasks in a clean lab environment
- Follow the existing folder structure

Contributions that make the material more useful for candidates are highly appreciated.
