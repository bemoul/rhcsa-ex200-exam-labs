
# RHCSA EX200 Exam Labs

Hands-on practice labs for the **Red Hat Certified System Administrator (RHCSA)** exam (EX200).

**Note**: This repo covers both RHEL 9.x and RHEL 10.x where applicable.

### Quick Links

- [YouTube Playlist](https://www.youtube.com/playlist?list=PLiI_-JOspy6FuSPXSipE0xE4oC2XXYyuI)
- [Official RHCSA Objectives](https://www.redhat.com/en/services/training/ex200-red-hat-certified-system-administrator-rhcsa-exam)

### Exam Versions

- **RHEL 9** → Includes Containers (Podman)
- **RHEL 10** → Includes Flatpak (newer)

### How to Use

1. Set up your lab environment (2–3 RHEL VMs)
2. Go through each section
3. Try tasks **before** looking at solutions
